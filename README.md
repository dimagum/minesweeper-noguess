# Minesweeper No-Guess

Сапёр, в котором поле генерируется так, что ситуаций угадывания (50/50) не бывает: любой уровень проходится **чистой логикой**. Работает в браузере и как десктоп-приложение (Tauri: macOS, Windows, Linux).

## Особенности

*   **Строгая гарантия No-Guess:** поле принимается, только если его проходит встроенный логический решатель. Кроме базовых правил и вычитания подмножеств он использует **глобальный счётчик оставшихся мин** и **перебор конфигураций по компонентам границы** — именно это устраняет финальные 50/50.
*   **Быстрая генерация:** ядро на Rust (WASM в браузере), локальный поиск с точечными мутациями. Поле Extreme 40×30 строится в среднем за ~3 мс нативно, генерация идёт в Web Worker — UI не подвисает.
*   **Подсказка:** решатель называет следующий логический ход из того, что видит игрок.
*   **Воспроизводимость:** поле полностью определяется seed'ом; после поражения можно сыграть то же поле ещё раз.
*   **Ежедневное поле:** одно и то же у всех в этот день (seed из даты), засчитывается первая попытка, есть серия дней подряд.
*   **Своё поле:** до 60 × 40; допустимая плотность мин зависит от размера, чтобы генерация оставалась быстрой.
*   **Статистика** по уровням: сыграно, процент побед, лучшее и среднее время, серии побед.
*   **8 мягких двухцветных тем**, плавные анимации, поддержка сенсорных экранов.

## Запуск

Нужны Rust (через `rustup`, с target `wasm32-unknown-unknown`), `wasm-pack` и Node.js.

```bash
cd web && npm install && npm run dev
```

`npm run dev` собирает WASM и запускает dev-сервер; `npm run build` — production-сборка в `web/dist/`.

Десктоп-приложение (из папки `web/`):

```bash
npm run tauri dev
```

```bash
npm run tauri build
```

Сборка кладёт пакеты в `target/release/bundle/` (на macOS — `.app` и `.dmg`). Собирать под Windows/Linux нужно на соответствующей ОС (или в CI).

Тесты и бенчмарк ядра:

```bash
cargo test --release
```

```bash
cargo run --release --example bench
```

## Механика No-Guess генерации

1.  **Безопасный первый клик:** мины расставляются только после первого клика, зона 3×3 вокруг него пуста (первая клетка — ноль, дающий каскад).
2.  **Случайная расстановка** остальных мин.
3.  **Верификация:** решатель проходит поле строгими логическими правилами — от дешёвых (одна цифра, подмножества) к дорогим (глобальный счётчик, перебор по компонентам границы).
4.  **Мутация вместо перегенерации:** если решатель застрял, мина у «застрявшей» границы меняется местами с клеткой в глубине, цифры пересчитываются точечно, проверка повторяется. Полное пересоздание — только если мутации не помогают.

## Управление

Схема мыши выбирается в меню (**Controls**):

*   **Classic:** ЛКМ — открыть клетку; ПКМ — флаг; **аккорд** (ЛКМ+ПКМ или средняя кнопка по цифре) — открыть соседей, если вокруг стоит нужное число флагов.
*   **Touchpad** (удобно на MacBook): клик — флаг; двойной клик — открыть клетку, а по цифре — аккорд. Первый клик партии открывает клетку сразу; двойной клик по клетке с флагом её не открывает.
*   **Сенсорный экран:** тап — открыть (по цифре — аккорд), долгое нажатие — флаг.
*   **H** — подсказка, **R** — новая игра, **Esc** — меню.
